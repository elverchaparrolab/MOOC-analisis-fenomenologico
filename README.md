# Laboratorio de análisis fenomenológico

Laboratorio de análisis fenomenológico (aplicación estática) y lecturas de apoyo del seminario de trabajo de grado (Maestría en Educación, UPTC), publicado con [Quartz](https://quartz.jzhao.xyz).

- Las notas están en `content/`, con la misma estructura de carpetas del vault de Obsidian.
- Para actualizar el sitio, reemplaza las notas en `content/` y sube los cambios: GitHub Actions lo vuelve a publicar solo.
- La página de inicio es el laboratorio: `laboratorio/index.html`. Es un solo archivo HTML sin servidor; el trabajo del estudiante se guarda en su navegador (localStorage) y se descarga en Word. Al publicar, GitHub Actions lo copia sobre el `index.html` que genera Quartz.
- Las secciones del curso siguen publicadas con Quartz como lecturas de apoyo de cada módulo.
